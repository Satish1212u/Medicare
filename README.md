# 🏥 MediCare - Healthcare Website

🚀 MediCare is a modern healthcare website that helps users find and choose hospitals based on their needs, services, and availability.

---

## 🌐 Live Demo

👉 https://medicareservices.netlify.app/

## 📌 Features

* 🏥 Browse and explore healthcare services
* 📅 Book appointments easily
* 🔍 Find hospitals based on user needs
* 💻 Clean and responsive UI
* ⚡ Fast and lightweight (no frameworks)

---

## 🛠️ Tech Stack

* 🌐 HTML5
* 🎨 CSS3
* ⚙️ JavaScript

---

## 🎯 Project Goal

The goal of this project is to simplify the healthcare experience by allowing users to easily discover hospitals and access medical services in a simple and user-friendly way.

---

